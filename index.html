PSL Email Tool

An internal desktop tool for drafting customs clearance service requests.

PSL Email Tool helps logistics staff prepare daily service-request emails to their customs agent. It reads the shipment tracker that each user already maintains in Google Sheets, lists the shipments still pending clearance, and creates draft emails in the user's own Microsoft Outlook with the matching shipping documents attached.

How it works

The tool runs on the user's own Windows computer. When it starts for the first time, the user signs in with their Google account and allows the tool to access Google Sheets. The tool then opens only the tracker the user selects in its settings. Drafts are never sent automatically; the user reviews and sends each email from Outlook.

Who can use it

The tool is used by a small internal team. It is not offered to the public.
